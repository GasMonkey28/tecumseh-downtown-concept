# QuoteDesk Studio — public portfolio snapshot

In-development self-owned product. This is the existing M1 browser interaction prototype adapted for GitHub Pages on September 17, 2026. The ongoing Flutter application, local Supabase services and later development are not deployed here.

Try a sample quote, select illustrations, write a follow-up, preview it, and revoke the preview. Customers, contractor and illustrations are fictional. AI, upload, sharing, credits and payment are simulations; there is no live billing or messaging. Quote totals and plan prices are sample product values, not Tecumseh proposal prices.

Only demo frontend files and the demo plan configuration were copied. No local server credentials, Supabase configuration, private photos, customer records, repository history or development documents were published. Edits save under a distinct public-demo localStorage key in this browser. Clear or reset using demo controls. This public app URL does not create a separate shareable customer quote link.
