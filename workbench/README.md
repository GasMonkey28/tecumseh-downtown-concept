# Content Workbench
Independent September 2026 portfolio demonstration by Vince Ma. Synthetic data only. No network writes, authentication, production CMS, real city data, or cloud services. Changes persist only until reload; export keeps a JSON review plan locally. Automated checks cannot certify accessibility or editorial approval. Proposed redirects are planning records, not server configuration. Duplicate targets require an explicit merge decision.

Run from the repository using `npm start`, then visit `/workbench/`. Tests: `node --test tests/workbench.test.mjs`.
