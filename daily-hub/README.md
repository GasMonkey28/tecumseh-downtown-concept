# Daily Hub — public portfolio snapshot

Adapted from the existing Daily Hub Windows dashboard UI on September 17, 2026. This is an in-development self-owned product, not a commissioned client website.

The original UI, styles and three-language interface are reused. A new in-memory adapter supplies exclusively synthetic calendar, task, project and contract records. The adapter is deliberately smaller than the private application's real server and must not be treated as evidence of live integrations.

Try Today, Week, task completion, privacy mode, Contracts and Settings language selection. Changes reset on reload. No real Gmail, Google Calendar, Codex, local files, OAuth, credentials, notifications or external writes. Content Security Policy disallows network connections from the app. Do not enter real private information.

No private database, export, screenshot, README, connector state or credential file was copied. Source directory is a snapshot; it does not track ongoing private development automatically.
